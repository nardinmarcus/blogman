# Triage labels

The engineering skills use the following canonical triage vocabulary.

| Label in Matt Pocock skills | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an independent implementation task |
| `ready-for-human` | `ready-for-human` | Requires human implementation or a human-only decision |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, use the corresponding tracker label above.
